DATA PROVENANCE • ML ARCHITECTURE

DATA & METHODOLOGY

Full technical documentation of the data layer, leak-free training pipelines, point-in-time joins, and calibration benchmarks.

Leakage Prevention System

Every single feature calculation strictly executes point-in-time joins with zero forward-looking leakage:

  • Module 1: Uses player_valuations.date ≤ match_date. No future season stats bleed into market estimates.
  • Module 2: Uses game_date < fixture_date. Rolling metrics, Elo, and rest days are calculated strictly on completed pre-match history.
  • Module 3: Unsupervised embeddings and K-Means segmentation isolate 2D representations from weighted Euclidean distances.

Data Layer & Sync

Hybrid architecture ensuring reliable offline execution with automated fallback:

  • Transfermarkt Datasets: 8 core tables downloaded from Cloudflare R2 and cached in data/raw/.
  • Football-Data.org Client: Cached fixture feed with offline synthetic schedule fallback.
  • Squad Overrides: Real-time mapping resolving recent summer and winter transfers.
